# iphost v0.4.0 planned changes

We add three opt-in features:

- `custom`: Enable the crate consumer to specify an alternative resolver's IP address (and optionally the bind interface or VRF)
- `ra`: using a netlink socket, queries an interface for v6 RA DNS settings. **Depends on `custom`**.
- `dhcpv6`: we do DHCPv6 Information-Request ourselves on the configured interface, and use that resolver set. **Depends on `custom`**.

## `Resolver` enum

**Non-exhaustive**.

- `Resolver::System`
- `Resolver::Static(StaticResolverConfig)`
- `Resolver::Ra(RaResolverConfig)`
- `Resolver::Dhcpv6(Dhcpv6ResolverConfig)`

where feature-gated variants exist.

Swapping `Resolver`s in runtime MUST be supported (not configured-once).

`.with_resolver()` constructor or such should be added to explicitly set the resolver, in addition to runtime-change methods.
